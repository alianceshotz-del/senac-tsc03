# UC8 — Planejar e executar auditoria de sistemas

Esta seção reúne os registros e materiais de estudo relacionados à UC8.

## Conteúdos registrados

- Preparação e atualização do Ubuntu Server 26.04 LTS.
- Configuração de rede com Netplan, endereço IP estático, gateway e DNS.
- Acesso remoto ao servidor por SSH.
- Levantamento de informações do sistema: distribuição, kernel, data e hora, rede, discos, memória, processador, pacotes, serviços, processos, usuários, grupos e conexões.
- Integração de Git, GitHub e VS Code para versionamento da documentação.
- Referências de auditoria, governança, segurança da informação e legislação.
