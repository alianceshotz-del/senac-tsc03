## Como utilizar

1. Consulte o README da UC desejada.
2. Acesse as pastas de aulas, levantamentos e projetos.
3. Consulte `docs/referencias/` para os materiais de apoio.
4. Ao adicionar novos materiais, mantenha os nomes claros e atualize o índice correspondente.

> Os documentos deste repositório são materiais de estudo. Confira a edição e a validade das normas e leis antes de utilizá-las em trabalhos formais.
